## 파일

1. `MOA_R709_EXACT_MEDIA_PREVIEW_ORIGINAL_SIGNED_BETA.apk` — 우선 설치할 새 기능 베타. 촬영 직후 알림의 정확한 원본 사진·영상 썸네일을 표시하고, 알림에서 기록 화면으로 들어가면 원본 미리보기 카드와 원본 열기를 추가합니다. 사진은 크게 보기, 영상은 재생 앱에서 보기를 지원합니다. 미리보기를 불러오지 못할 때 임의의 다른 사진으로 바꾸지 않으며 원래 메모/음성 입력과 저장 동작을 유지합니다.
2. `MOA_R710_EXACT_R707_FUNCTIONAL_FORWARD_RECOVERY_ORIGINAL_SIGNED.apk` — R709에서 문제가 발견됐을 때 사용하는 **R707 기능 그대로의 상위 버전 복구본**입니다. 이 복구본에는 R709 새 미리보기 기능이 들어 있지 않습니다.
3. `MOA_R709_R710_STATIC_QA_REPORT.json` — 자동 정적 검증 기록. 기기 설치/실사용 테스트는 별도로 필요합니다.

## 설치 전 주의사항

- 앱을 삭제하거나 데이터를 지우지 마세요. 기존 가족 사진·메모·일기 데이터가 보존되어야 합니다.
- 현재 정상 작동하는 R707을 기준으로, **R709를 기존 앱 위에 업데이트**합니다. 동일 패키지·기존 서명 인증서를 유지했습니다.
- R709 후 문제가 생기면 **R710을 기존 앱 위에 설치**해 R707 기능을 복구합니다. R710 설치 후에는 버전코드가 더 낮은 R709를 일반 업데이트로 다시 설치할 수 없으므로, 새 수정본은 R711 이상으로 발행해야 합니다.
- 설치 중 서명 불일치·파싱·정책 오류가 뜨면 강제로 삭제하지 말고 오류 메시지/화면을 기록해 주세요.
- 앱이나 Android 자체의 알림 권한, 사진·영상 접근 권한 설정은 유지되어야 미리보기가 나타납니다.

## R709 확인 순서

1. 새 사진을 한 장 촬영한 직후 알림을 내려 **그 사진 썸네일이 정확히 표시되는지** 확인합니다.
2. 알림을 눌러 메모 화면에서 **같은 사진**의 미리보기가 나오는지, 탭해 크게 볼 수 있는지 확인합니다.
3. 새 영상 촬영 후 알림 썸네일 및 메모 화면의 영상 표시, 원본 재생을 확인합니다.
4. 사진·영상을 연속으로 촬영한 뒤 각각의 메모 대상이 뒤섞이지 않는지 확인합니다.
5. 글 메모·음성 받아쓰기·저장·모아 일기 동기화·기존 갤러리 및 위치 기능을 점검합니다.
6. 잠금화면에서는 사적인 썸네일이 그대로 보이지 않는지, 잠금 해제 알림에서는 확인 가능한지 점검합니다.
