# MOA AppFunctions link lab — separate package, synthetic only
Goal remains automatic ordinary ChatGPT learning with maximum thinking and no agentic allowance consumption; not demonstrated by this lab. Official AppFunctions provider API only. No Internet permission, no accessibility, no account/session credentials, no ChatGPT automation, no production MOA data. Android API 36+; official sample toolchain pinned (AGP 9.5.1, Gradle 9.9.1, KSP 2.3.13, AppFunctions rc01, compileSdk 37.0). App displays actual package permission checks, not proof of execution. Local consent arms a single fixed synthetic job; official authorized caller can claim and submit; result is durable plain text. ADB testing is for this lab only. Never invoke unknown ChatGPT functions. No Golden modification.
Build: gradle -p experiments/moa-appfunctions-link-lab :app:testDebugUnitTest :app:assembleDebug
Device gate: install separate debug APK; register synthetic fixture; use official app_function list-app-functions --package com.juhyeon.moa.linklab and inspect exact function IDs; invoke the lab functions with authorized test agent only. Do not grant privileged permissions by bypass or change ChatGPT settings. Real ChatGPT authorized caller/ordinary chat initiation/usage measurement remain gates. No claim of full learning or actual model execution.
References: https://developer.android.com/ai/appfunctions/add-appfunctions ; https://developer.android.com/ai/appfunctions ; https://github.com/android/appfunctions ; https://developer.android.com/agents/skills/device-ai/appfunctions/references/adb-interaction-testing .

CI is isolated: it builds only the lab package with its debug signing identity. It must never publish to moa-update-channel or replace the installed MOA app. SDK/Gradle availability and device registration require actual evidence.

Compatibility retry uses the official alpha10 documented API-36 toolchain; this does not establish any additional ChatGPT execution rights.

API 36 fallback rejected by actual AAR metadata; Android 17 SDK is published as android-37.0, not android-37. Use the official minor API compileSdk DSL. Evidence: https://github.com/actions/runner-images/issues/13859 and https://developer.android.com/build .
