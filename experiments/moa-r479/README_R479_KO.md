# MOA R479 통합 달력 UI 베타 · R481 원본 골든 복구

현재 사용자 승인 공식 골든은 **R463**입니다. R479는 골든을 훼손하지 않은 별도 후보 APK입니다.

## 설치
1. 현재 모아를 제거하지 않고 **R479 APK를 덮어쓰기 설치**하세요. 앱 데이터, 네이버 로그인 쿠키, 기존 사진·일기·음성·가족 일정을 초기화하지 마세요.
2. 기존 `일기` 탭에서 단일 통합 달력 확인: 상단 `우리 가족 일기`/홈/통계 제거, 빈 날짜 흰색, 달력 외곽 둥근 형태, 날짜 최하단 일정 표시선, `오늘` 아래 `선택/전체` 작은 좌우 버튼.
3. 사진 날짜 누르기 → 기존 사진형 일기, 사진형 ↔ 상세형 27px 작은 전환과 기존 미디어/일기 내용 확인.
4. 달력 본문을 좌우로 빠르게 밀어 월 이동, `2026년 11월⌄` 제목을 누르면 연도·월 패널, `오늘`로 현재 달 복귀.
5. 일정 표시 날짜를 누르면 사진형 일기의 `가족 일정`에서 확인하고 일정을 누르면 날짜 내부의 수정창 열림. 별도 가족 일정 캘린더 버튼은 UI에서 제거. 내부 저장소 `moa-family-calendar-v1/events` 사용.
6. 원래 기능 이상 시 **R481 APK 덮어쓰기 설치**: R463의 기능 본문을 그대로 복구하되 versionCode만 481입니다. R481 설치 후 다음 APK versionCode는 반드시 >481.

## 실제 구현 내용
- 같은 사진 일기 달력 1개. 선택/전체 사진은 원래 저장된 curated/automatic MediaStore 목록 표시 모드만 전환. 새로운 사진 일기 DB, 새 보조 앱, 별도 가족 일정 캘린더를 만들지 않음.
- 사진이 없는 날짜 및 빈 여백 흰색, 단일 라운드 23px 사진 격자, 일정은 날짜 아래쪽 3px 선. 셀에 사진/영상 개수 표시하지 않음.
- 연월 이동: 커스텀 연도 변경/12개월 선택 시트. 월 본문은 pointer 기반 드래그 애니메이션/속도별 최대 5개월 건너뛰는 연속 플링. 이는 R203 원본 네이티브 갤러리 관성 엔진을 이식한 **것이 아니라** 독립적인 달력 웹 드래그 구현임.
- 기존 5개 하단 메뉴 `일기 / 나의 지도 / + / 기록 / 설정` 보존.
- 원래 앱 DEX 17개 변경 없음, NAVER/음성/원래 고급 갤러리 웹 자산 변경 없음. 원본 앱의 140개 엔트리 중 138개 payload 원본 동일. 새 JS/CSS 두 파일 추가, manifest 버전 및 index 로더 2줄만 변경.

## 검증 상태
- `node --check` PASS.
- Chromium 합성 사진 13장으로 단일 사진 달력/화이트 빈칸/라운드/가족 일정 3px 선/두 사진 범위/월 선택/관성 드래그/오늘 복귀/같은 날짜 사진형 및 내부 가족 일정 선택을 테스트함. **테스트 기기의 진짜 사진·일정·영상·쿠키는 포함되지 않음.**
- APK Signature Scheme v2 RSA signature/full signed content digest, 원본 R463 인증서 동일, ZIP CRC, 4-byte aligned stored entries, DEX 17개 동일 PASS.
- 미검증: 실제 Galaxy S26 Ultra Android WebView 월 플링 감각/속도, 원본 가족 일정 DB 실제 쓰기와 서비스 캐시 반영, 1만 4천+ 사진 대용량 성능, 네이버 비점유 저장 리그레션, 원본 R203 네이티브 영상/갤러리의 새 일기 화면 내 완전 동등 기능. 완전한 GOLDEN/실기기 PASS라고 주장하지 않음.
