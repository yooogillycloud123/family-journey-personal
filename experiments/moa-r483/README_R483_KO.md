# 모아 R483 세로 연속 사진 달력 · R485 원본 복구

**공식 사용자 골든은 기존 R463**입니다. R483은 새 UI를 시험하기 위한 버전이며 실기기 검증 전입니다.

## 설치
1. 현재 모아를 삭제하지 않고 R483 APK를 **덮어쓰기 설치**하세요. 앱 데이터, 네이버 쿠키, 사진, 음성, 일기 저장소를 삭제하지 마세요.
2. 기존 일기 탭의 메인 달력에서 위아래로 자연스럽게 스크롤하여 11월, 12월, 1월 등 연속 월을 탐색합니다. 더 위로 스크롤하면 이전 월이 이어집니다. **최대 5개월 점프했던 기존 R479 가로 스와이프는 제거했습니다**.
3. 오늘 날짜는 날짜숫자 배경이 아니라 셀 **전체 테두리**로 강조합니다. 가족 일정이 있는 날은 사진을 침범하지 않는 9px 하단 전용 띠에 작은 선이 나타납니다.
4. 상단의 '오늘' 버튼 아래에는 **글자/아이콘 없는 2위치 타원 슬라이더**가 있습니다. 왼쪽 = 내가 고른 사진, 오른쪽 = 전체 사진. 좌우 드래그·터치로 변경합니다.
5. 연월 제목을 탭하면 **연도 1900~2100 스크롤 목록 + 12개월 버튼**이 나타납니다. 연도와 월을 선택하여 이동합니다.
6. 날짜를 열면 큰 사진 영역 위의 **글자 없는 소형 슬라이더**로 '사진형'(왼쪽)/'상세형'(오른쪽)을 바꿉니다. 원본 상세형은 삭제하지 않았으며 기존 바로기록/시간대별 데이터 저장소를 그대로 사용합니다.
7. 가족 일정은 각 날짜 하단의 미세한 선 및 날짜 내부 '가족 일정' 목록에서 확인/편집할 수 있습니다. 기존 독립 달력은 UI에서 숨긴 것으로, 저장된 이벤트나 알림 기능 코드를 삭제한 것이 아닙니다.
8. 심각한 회귀가 발생하면 R485를 **덮어쓰기 설치**하세요. R485는 원본 R463 기능 파일이 그대로이며 versionCode만 485입니다. R485 설치 후 새 빌드는 versionCode >485여야 합니다.

## 검증과 미검증
- 노드 JavaScript 파싱 PASS. Chromium 합성 데이터 UI 테스트 PASS (상하 연속 월·미세 일정선·전체 테두리·연도목록·소형 슬라이드·상세형 원복).
- APK v2 RSA 서명 및 전체 다이제스트, R463과 같은 인증서, 원본 DEX 17개·ZIP 무결성 PASS.
- **실제 갤럭시 설치/스크롤 감각, 14,000장 사진 색인, 일정 IndexedDB 쓰기, 기존 네이버 비점유 저장, 새 사진형 안의 고급 네이티브 갤러리/영상 재생은 아직 실기기 검증하지 않았습니다.** R483을 골든으로 확정했다고 주장하지 않습니다.
- 새 달력 연속 스크롤은 Android WebView 자체 관성(세로 overflow)이며 원본 R203 갤러리 하단 전용 네이티브 관성 엔진 이식은 아닙니다.

서명 개인키, 가족 사진, 네이버 로그인 정보, 개인 데이터는 ZIP에 포함되지 않습니다.
