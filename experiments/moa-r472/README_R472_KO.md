## R469 -> R472 개선 내용
1. 달력: 사진의 날짜가 기존 회색 배지와 분리돼 보이던 것을 작고 은은한 사진 위 표기로 변경. 사진은 칸에 꽉 채우되 아직 안 온 사진은 중립 배경으로 보여서 액박/대체 텍스트가 튀지 않도록 함.
2. 달력 썸네일: 초기 사진 브리지 미준비, 네이티브 응답 지연, 외부 앱에서 복귀했을 때 더 잘 회복하도록 비동기 2.5초 워치독, 1.6초 재시도, 최대 6회 요청·가시 영역 우선 로드·이미지 캐시 관리. 단, 갤럭시 실기에서 모든 사진/영상 썸네일 재현 검증은 아직 없음.
3. 큰 사진 영역: 기존 R469의 'JS 인덱스 이동 후 화면 전체 리렌더' 대신 같은 페이지 안에서 가로 overflow scroll-snap을 적용. 기본은 한 장씩, 빠른 넘기기 ON에서는 스냅 해제 및 WebView의 관성 스크롤 사용. 사진 수가 많아도 근처 사진을 미리 요청하고 영상 슬라이드로 이동하면 기존 영상 오디오 정리. **이것은 R463 네이티브 R203 엔진 자체와 같은 것이 아님.**
4. 썸네일: 달력은 260px, 큰 사진은 1024px 크기로 네이티브 요청(원본 고해상도 수신은 기기 네이티브 서버 구현/응답에 따라 제한될 수 있음). 작은 썸네일을 먼저 보여주고 더 큰 이미지 수신 시 대체. 실제 모든 원본화질을 보장하지 않음.
5. 하단 탭: **일기 / 나의 지도 / 중앙 + / 기록 / 설정** 5개로 재배치. 기존 가족 일정은 일기 내 '가족 일정'으로 접근하고 독립 6번째 탭에서 숨김. 기존 이벤트 핸들러가 붙은 버튼 자체를 DOM 이동해서 원래 기능을 보존. 중앙 +는 선택 날짜의 사진 일기로 바로 진입(원본 일기가 닫혔다면 먼저 열기).
6. 달력 내부 중복 '+' 버튼 제거. 연도/월 선택은 WebView 기본 prompt 대신 앱 기존처럼 Android native `<input type=month>` 사용. 원래 수동/자동 달력 지우지 않음.
7. 기존 R469 대표 사진 ID, 공유/GPS, 날짜별 일기 내용, 여러 음성 레코딩 목록, 일기 DB는 동일하게 유지. 원본 검은 전체화면 갤러리 별도 진입을 기본 사용 경로로 만들지 않음.

## 아직 완료라고 주장하면 안 되는 항목
- **R463 원본의 R203 OverScroller 관성 엔진을 새 인라인 갤러리에 직접 이식한 것이 아님**. WebView의 물리 스크롤을 사용했지만 제스처가 완전히 같은지는 실기 확인 필요.
- **영상이 사진일기 카드 안에서 100% 재생되는 것은 미확인**. WebView가 content://MediaStore URI 접근을 허용할 때 인라인 HTML5 video 재생을 시도하고, 거부되면 기존 원본 네이티브 플레이어로 이동할 수 있도록 폴백. 실기 테스트 필수.
- 원본 네이티브 비디오 1% 탐색, 음량 스와이프, 프레임 캡쳐, 핀치/더블탭 사진 줌, 음성 파형/탐색을 동일하게 새 카드 안에서 사용할 수 있다고 확인된 것은 아님.
- 초기 화면/갤러리 플로우와 네이버 비점유 저장을 포함한 전체 실기 기기 통과 확인은 아직 없음.
