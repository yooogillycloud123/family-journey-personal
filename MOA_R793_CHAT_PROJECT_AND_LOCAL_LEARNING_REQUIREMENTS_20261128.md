## Supported design
1. Optional ordinary ChatGPT project mode: user-created private project "모아 AI 학습"; persistent project instructions below. MOA prepares a user-selected batch of registered missing/partial photo/video study jobs, scene frames and optional diary text, with opaque local mapping IDs. User explicitly shares/uploads selected media and prompt into ordinary Instant chat (not Work). User manually copies/exports the response and imports via MOA. No automatic UI injection, private endpoints, automated response extraction, session reuse to evade limits, or parallel accounts. Ordinary chat/image uploads have their own limits; opening new chat does not reset quotas. Full unattended cloud generation through ordinary chat is not supported by verified official interfaces.

No silent fallback or lower quality completion; draft vs verified complete separate. Local generation does not use ChatGPT allowance but OS/device restrictions remain.
3. Retain current R791 external automatic engine as opt-in; respect provider limits and explicit quota/consent. No claim of fixed percentage savings without measurements.

Import requirements: inspect exact R791 native schema first; import preview, stable opaque ID matching, curated-only check immediately prior to write, schema/subject/quiz and size validation, no executable HTML, atomic durable per-card save, dedup and no overwrite completed card without explicit approval, preserve vocabulary/audio/review state and all other modules.
