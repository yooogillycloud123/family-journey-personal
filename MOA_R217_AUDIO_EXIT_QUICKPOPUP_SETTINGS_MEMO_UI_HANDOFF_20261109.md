## Root causes and fixes
1. **Diary audio persists:** `MoaMomentAudioHostActivity.onPause()` previously stopped video/recording/speech but not its private `MediaPlayer` (only `onDestroy` released it). Native bridge was missing `stopPlayback()`, while `moa-r149-voice.js` tracked UI state separately. R217 adds public `r217StopPlayback` releasing this player, clearing active playback, sending finished event. Calls on Android onPause (Home/background) and exposes `@JavascriptInterface stopPlayback()` marshalled to main UI thread via `MoaR217StopPlaybackRunnable`. JS uses explicit native stop when voice overlay closes, on pagehide/visibility hidden, or when the diary root/state closes (350ms polling). Only listening ends; M4A recorder and saved original voice files remain protected.
2. **Settings invisible:** R215 popup settings were appended to `#moa-r117-photo-settings .moa-r117-inner-rows` and gave up after 50×350ms if the photo settings accordion wasn't created. R217 mounts a **dedicated visible top-level card under `section.page[data-page="settings"] > ul.rows`**, retries every 1250ms, reattaches after settings DOM recreation/pageshow. Existing native `MoaMomentApplication$CaptureBridge.quickPopupPrefs/setQuickPopupPrefs` still persists values. Autoshow choices 0/1/2/3/5/7/10/15/20/30/60 secs, plus direct numeric 1–60sec. Default size for first-time configuration 85% instead of R215 100%; preserves previously explicitly stored choices.
3. **AssistiveTouch-inspired quick popup:** Recompiled the same original native `MoaR215QuickOverlay` with tighter capsule proportions, smaller red record symbol and clearly smaller X icon (the X hit View still at least 44dp), retaining original record and dismiss `PendingIntent` callbacks, long-press edit, move/resize, orientation-aware persistence, safe region and timer settings. No changes to detection/notifications or service core.
4. **Native quick memo panel old styling:** Actual `MoaMomentMemoRecorderActivity` is a **native Android Activity**, not WebView. Added only one safe onCreate call to independent `MoaR217MemoPolish.apply(Activity)`. It restyles existing EditText, Buttons, titles, caption (rounded card, soft MOA red accents, short introduction, accessible typography) and initially folds backup/archiving descriptions, autoArchive checkbox and backup control behind `녹음 보관 · 백업 설정` expandable label. The existing views/listeners, original voice record/play/capture note/save and backup controls are **not replaced/deleted**. Styling errors catch and must not interfere with saving.
