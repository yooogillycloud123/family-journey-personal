- **Explicit R592 path:** if the original native opener **returns false**, code simply clears `__moaR507NativePending` and returns. If bridge never becomes ready or Java arm never becomes true, it times out without usable UI recovery. For an opener that returns true but never emits native mounted ACK, R592 deliberately keeps native owner/pending forever. R592 CSS also unconditionally hides original Web gallery controls throughout photo-view; therefore all three paths can leave a black/gray and untouchable stage. App restart retries saved identical IDs, so the failure may recur. This is a source-confirmed **persistent failure-state bug**, not yet proof that any specific particular MediaStore ID was missing or that native open returned false on user's phone.
