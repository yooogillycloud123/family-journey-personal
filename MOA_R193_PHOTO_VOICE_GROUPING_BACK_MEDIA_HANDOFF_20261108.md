## Feature/UX details
1. **Photo-specific textual memo, including previously blank media**: every selected photo/video gets an independently collapsed `기록` panel with `＋ 메모 남기기` / edit and a voice-record action. A new moment is created in curated IndexedDB with the exact `photoIds` link only on explicit Save. Existing captured moments editable. If multiple media IDs share one moment, only the actual associated IDs show it; never silently reassign/migrate old user data.
2. **Photo-specific native voice**: sanitized exact `voiceFileId / voiceDay / voiceRecords` from native capture persisted as `moments[].voiceIds` along with originally associated `photoIds`, even for empty note. The audio file stays in existing private M4A store. Clicking `🎙 이 사진에 녹음` opens the same native recorder; before/after M4A list determines exactly the newly created file and `__moaPhotoVoiceSaved(day,mediaId,fileId)` binds it. Existing M4A can also be manually selected and linked to a specific photo when old ACK metadata cannot be recovered. Time-only voice without photo linkage remains in the time group/standalone audio list; linked audio is not displayed twice at the group top. No timestamp-based guesses or forced migration.
3. **Audio elapsed / total**: native LocalBridge adds trusted **read-only `durationMs(day,id)`** based on the actual M4A MediaMetadataRetriever with day/id validation. Voice UI uses this plus native playback updates to show `00:03 / 00:31`; unknown media may show `--:--` rather than a fabricated value. Playback/pause and original voice file unmodified.
4. **Back stack**: updated `__fjBackOverlay`, `Escape` and visible state ensure the nearest open photo-record fold/editor or date action/settings modal closes before date → calendar; respect unsaved editor changes. Native record modal and existing voice drawer Back integration preserved as far as browser source can verify. Not every platform Back gesture tested until real device.
5. **Time grouping**: `⋯ → 보기 설정` allows **5,10,15,30,60,120 minutes**, persisted to localStorage; **default 60min**. These are presentation buckets only. Original 5min `activityKey`/native audio/moment capture time remains unchanged. Groups aggregate old manual activity text without data rewrite; avoid duplicating native-photo moments. Clicking the displayed time **range** triggers existing `showRecorder(day,slot)`, no separate red mic; saved voice rows remain foldable.
6. **Larger/photo-first**: default **two media columns**, user-selectable 1/2/3 columns under same view settings. Photos and video placeholders grow; media actions compressed into separate fold; concise symbols instead of awkward `메모 없음`.
7. **Video frame-strip staircase**: existing native R187 MediaPlayer/TextureView seek retained, but random-seek decoded frame previews are collected off-main and posted into `scrubFrames` **as a single batch with one UI invalidate**, capped at 22 frames. In progress displays short loading text; does not guarantee Samsung proprietary decoder parity. Android CI compile PASS; actual device latency/jank still requires real observation.
