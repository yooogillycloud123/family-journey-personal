## What is actually implemented
R245 full-screen black Accessibility overlay was a fake/blocked UI. R249 instead obtains the **actual existing MOA HostActivity WebView**, removes it temporarily from original Activity content view, reparents into **TYPE_ACCESSIBILITY_OVERLAY** rooted in the SAME package's already user-enabled `NaverSaveService`. The underlying real first-party `com.nhn.android.nmap` window remains accessible to that service while the user sees **and can touch actual MOA UI**. Original View, JS state, NativeHost bridge and original parent/index/layout parameters are preserved. On cancel/terminal status/timeout, WebView reparented back, same HostActivity resumed via `CLEAR_TOP|SINGLE_TOP`. A small status/cancel chip is displayed only during the job. No helper APK, no PC, no root, no Shizuku, no Samsung Internet login session manipulation or private credential requests.

Android official evidence for this precise behavior: `AccessibilityWindowInfo.TYPE_ACCESSIBILITY_OVERLAY` preserves underlying window introspection even if fullscreen/touchable: https://developer.android.com/reference/android/view/accessibility/AccessibilityWindowInfo ; `AccessibilityService` supports interactive overlays: https://developer.android.com/reference/android/accessibilityservice/AccessibilityService . This is a **real UI relay**, not an Android secure background launch or true completely offscreen app. User may continue MOA interactions, but running other unrelated apps unhindered isn't proven.

Existing `HostActivity` native `naverSave` first-party intent/Accessibility logic and `NaverSaveService` are reused. If service fails or actual MOA WebView can't attach, new guard prevents external NAVER foreground launch. R245 user-despised manual six-field Settings tester and repeated `prompt()` place/list questions are removed. Existing diary/photo original GPS `diaryMediaLocation` / reverse address / saved list+alias+memo now construct the request automatically through `FamilyJourneyNaver.saveFromDiaryGps`. If verified real venue title is absent, only an exact **address location** search is attempted, not an invented business ID; **this is not proof the intended business is identified**. Native accessibility memo 50-char truncation is raised to 400, and existing editable-field UI match still governs whether memo entry proceeds.
