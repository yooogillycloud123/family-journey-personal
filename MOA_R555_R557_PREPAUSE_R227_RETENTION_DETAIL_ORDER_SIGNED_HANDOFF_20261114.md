## Source-confirmed fundamental causes
**(1) PHOTO→DETAIL deterministic ownership inversion**: R551 `experiments/moa-r483/moa-r483-vertical-calendar.js`, `r475OpenDetail(day)` called `FamilyJourneyDiary.selectDay(day)` **before** `close()`, and `close()` invokes `r507StopInline()` → `MoaLocalAudio.closeNativeGallery()`. That means R551's photo teardown can close the Gallery *just opened* by the detailed original Diary. R555 sets deliberate transition guard, closes photo-only Gallery FIRST, then calls the original `selectDay` exactly once to open the new native/detail owner. No replacement of the original Diary form/data.

**(2) ACTIVITY PAUSE deterministic ordering fault**: The actual preserved original R227 source in [R227 branch `experiments/moa-r175/MoaNativeGallery.java`](https://github.com/yooogillycloud123/family-journey-personal/blob/feature/moa-r227-gallery-nav-return-original-gps-expanded-video-20261109/experiments/moa-r175/MoaNativeGallery.java) exposes `r227ExternalMapPending`, `r227VideoWasPlaying`, `r227RetainForExternalMap()` = `open && pending`, and `r227ResumeFromExternalMap()`. [Original Android HostActivity smali patch](https://github.com/yooogillycloud123/family-journey-personal/blob/feature/moa-r227-gallery-nav-return-original-gps-expanded-video-20261109/experiments/moa-r227/patches/MoaMomentAudioHostActivity.smali.patch) proves `MoaMomentAudioHostActivity.onPause` calls `r227RetainForExternalMap` and immediately `MoaNativeGallery.close()` if false. Prior R535–R551 supplementary callbacks did not set the retention flag before original `onPause` (they generally acted at/after ordinary `onActivityPaused`), so when entering Recents/Home/foreign app the original host could destroy its own media renderer **before** our deferred rebind.

Android official [Application.ActivityLifecycleCallbacks](https://developer.android.com/reference/android/app/Application.ActivityLifecycleCallbacks) explicitly documents `onActivityPrePaused` (API29+) **before** `Activity.onPause` and `onActivityPostResumed` (API29+) **after** `Activity.onResume`. R555 new `classes18.dex` binds this exact pre-pause moment for the **trusted https://familyjourney.local original MoaNativeGallery** (in-card, detailed, full-gallery). It faithfully sets original R227 pending/playing fields, pauses video only if currently playing, calls original `r227RetainForExternalMap` before host's close decision. The original `onResume` should restore selected media/time/play state; optional post-resume invokes original idempotent completion only while pending. No system privileges/permission changes, no alteration to original Gallery DEX, private data, Naver, or recorder.

**(3) PIXEL QUANTIZATION micro jitter**: Existing R527 browser `WebMessagePort` pushes CSS subpixel stage coordinates, but old Java projected them by `Math.round` to integer x/y, causing adjacent pixel toggling at subpixel positions (in addition to unsynchronized WebView/Android compositor frames). R555 preserves the successful R527 no-overshoot one-way geometry channel and uses fractional float GPU `setTranslationX/Y` for both push path and snapshot fallback, *without* the harmful R539 `alpha=0` proxy/duplicate Web viewer. **Not a guarantee of zero jitter**; independent Android native/WebView surfaces cannot be hard-frame-locked by this patch.
