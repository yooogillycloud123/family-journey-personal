## Design verified from primary sources
Android AppFunctions is an app capability provider; execution by other apps requires privileged system-granted EXECUTE_APP_FUNCTIONS/EXECUTE_APP_FUNCTIONS_SYSTEM. Registration, permission discovery and result return are distinct from starting a ChatGPT Project model session. Current official ChatGPT Android documentation does not establish an external, unattended ordinary-chat entry point or support for AppFunctions. Official samples use provider service and KSP metadata. Test ONLY the lab functions, not unknown ChatGPT functions; no privilege grants, app settings alteration, or protected interfaces. The lab demonstrates a permitted data transfer component if compiled and physically verified; it cannot itself provide model access or prove usage exemption. No unsupported execution claims.
Sources: https://developer.android.com/ai/appfunctions ; https://developer.android.com/ai/appfunctions/add-appfunctions ; https://github.com/android/appfunctions ; https://developer.android.com/reference/kotlin/android/app/appfunctions/AppFunctionManager ; https://help.openai.com/en/articles/8142208-chatgpt-ios-and-android-app-faq ; https://openai.com/policies/terms-of-use/ .
