## Technical root cause and fix
1. Original `MoaMomentMemoRecorderActivity$3.onListening()` set `micButton.setEnabled(false)`; no second-tap STOP possible. R223 sets it enabled and updates label to **기록 종료**. Original `onFinished()` restored `🎙 음성으로 말하기`; R223 restores **음성 기록**, enabled. Original `startDictation()` always stopped old recognizer and started another; R223 checks active label: if recording, put UI into **인식 정리**, temporarily disable, then call existing `MoaMomentVoice.finish()` to invoke `stopListening()` and allow final recognition callback. Importantly UI changes precede asynchronous `finish()` to avoid a race where a synchronous `onFinished()` would be overwritten by a later disabled state. If previous recognizer already finished, it is cleared on next start as before. Existing Android audio permission request, file transcription exclusion and original speech/append/save listeners are preserved.
2. Quick memo initial button texts are consistently **음성 녹음 | 음성 기록 / 녹음 듣기 | 전체 삭제 / 일기 저장**, with original `Button` objects, click listeners and original data-saving storage untouched. Active speech state uses 기록 종료; original file recording can still display its duration.
3. Existing upper `ScrollView` editor card uses approximately 16dp outer horizontal inset, while footer had none. R223 applies matching **16dp left/right margins** to the floating bottom footer, 7dp inner padding and 3dp each cell side + row spacing; footer corners now align with the upper editor border. 44dp high cells retain accessible tap area. Automatic 11–14sp captions + ellipsizing avoid clipping on narrow devices. Save stays MOA pink, quieter other buttons share one surface.
4. Native keyboard: use the original IME inset/resize path and weighted EditText scroll, adapt EditText minimum height to approx 106dp when Android30+ IME shown and 180dp when hidden; footer stays in layout rather than overlaying system keyboard. This is a layout strategy; real Galaxy IME/landscape QA pending.
5. Original gallery upper stage one-photo step/lower rail inertia, vertical volume above mute, R221 floating popup eight-direction resizing, original user records, quick photo capture, recording/M4A file, diary save and backup are unchanged.
